# Grocery Management System

A simple Python-based Grocery Management System that helps manage grocery products and perform basic inventory and billing operations.

## Features

- View all grocery products
- Add new products
- Search for products
- Update product details
- Delete products
- Buy products
- Generate a simple bill
- Automatically update product quantity after purchase

## Technologies Used

- Python
- Dictionary
- Loops
- Conditional Statements
- Basic Input/Output

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
py main.py
